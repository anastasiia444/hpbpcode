# Як запустити бота

Інструкція покрокова, програмувати не потрібно. Займе приблизно годину.

Вам знадобляться:
- **Токен Telegram-бота**: безкоштовно, 2 хвилини.
- **Ключ Claude API**: оплата за використання.
- **Сервер (VPS)**: приблизно $5–10 на місяць.
- **Google Calendar**: необов'язково, без нього бот теж працює.

---

## Крок 1. Створіть бота в Telegram

1. Відкрийте в Telegram **@BotFather** і надішліть `/newbot`.
2. Придумайте назву (наприклад, «Мій рекрутер») і username, що закінчується на `bot`.
3. BotFather надішле **токен** — рядок на кшталт `123456789:AA...`. Збережіть його, він знадобиться в кроці 5.

Токен — це пароль від бота. Не пересилайте його нікому, зокрема в чат зі мною.

## Крок 2. Отримайте ключ Claude API

1. Зареєструйтеся на [platform.claude.com](https://platform.claude.com).
2. У розділі **Billing** поповніть баланс (для початку вистачить $10–20).
3. У розділі **API Keys** натисніть **Create Key** і збережіть ключ (`sk-ant-...`).

Скільки це коштує: бот працює на моделі Claude Opus 5.5. Звичайне повідомлення коштує орієнтовно кілька центів, оцінка великого PDF-резюме — дорожче. Витрати видно в розділі **Usage**. Там же можна поставити місячний ліміт.

## Крок 3. Орендуйте сервер

Підійде найпростіший VPS у будь-якого провайдера (Hetzner, DigitalOcean, Vultr тощо):
- система **Ubuntu 24.04**;
- 1 ГБ оперативної пам'яті, 1 процесор.

Після створення провайдер дасть **IP-адресу** і пароль (або SSH-ключ) для користувача `root`.

Підключіться до сервера з Терміналу на Mac:

```
ssh root@IP-АДРЕСА
```

Встановіть Docker однією командою:

```
curl -fsSL https://get.docker.com | sh
```

## Крок 4. Скопіюйте бота на сервер

На **Mac** (новий Термінал, не на сервері) виконайте:

```
cd ~/Desktop/"AI агент"
rsync -av --exclude data --exclude .git --exclude .env ./ root@IP-АДРЕСА:/opt/recruiting-bot/
```

## Крок 5. Налаштуйте і запустіть

На **сервері**:

```
cd /opt/recruiting-bot
cp .env.example .env
nano .env
```

Заповніть `TELEGRAM_BOT_TOKEN` і `ANTHROPIC_API_KEY`. `ALLOWED_TELEGRAM_USER_ID` поки залиште порожнім. Збережіть файл: `Ctrl+O`, `Enter`, потім `Ctrl+X`.

Підготуйте папку для бази і запустіть бота:

```
mkdir -p data && chown -R 1000:1000 data .claude
docker compose up -d --build
```

## Крок 6. Прив'яжіть бота до себе

1. Напишіть своєму боту в Telegram будь-що. Він відповість: «Ваш Telegram ID: 123456789».
2. На сервері відкрийте `nano .env` і впишіть це число в `ALLOWED_TELEGRAM_USER_ID`.
3. Перезапустіть бота: `docker compose up -d`.
4. Напишіть боту `/start`. Тепер він відповідає лише вам.

---

## Крок 7 (необов'язково). Google Calendar

Тоді бот бачитиме, коли ви зайняті, і сам створюватиме події для інтерв'ю.

1. Відкрийте [console.cloud.google.com](https://console.cloud.google.com) і створіть новий проєкт.
2. **APIs & Services → Library** → знайдіть **Google Calendar API** → **Enable**.
3. **APIs & Services → Credentials → Create credentials → Service account**. Назва довільна, наприклад `recruiting-bot`. Ролі не потрібні.
4. Відкрийте створений сервісний акаунт → **Keys → Add key → Create new key → JSON**. Завантажиться файл.
5. Скопіюйте цей файл на сервер (на Mac):
   ```
   scp ~/Downloads/НАЗВА-ФАЙЛУ.json root@IP-АДРЕСА:/opt/recruiting-bot/data/google-service-account.json
   ```
   Потім на сервері: `chown 1000:1000 /opt/recruiting-bot/data/google-service-account.json`
6. Відкрийте [Google Calendar](https://calendar.google.com) → налаштування свого календаря → **Спільний доступ для певних людей** → додайте email сервісного акаунта (виглядає як `recruiting-bot@….iam.gserviceaccount.com`) з правом **«Вносити зміни в події»**.
7. У `.env` впишіть `GOOGLE_CALENDAR_ID=` вашу Gmail-адресу і перезапустіть: `docker compose up -d`.

Обмеження: сервісний акаунт не може надсилати кандидатам запрошення від вашого імені. Бот створить подію з контактами кандидата в описі, а запросити людину ви зможете одним кліком у самому календарі.

## Як користуватися

- Пишіть боту звичайними словами або надсилайте резюме файлом (PDF, DOCX).
- `/today` — план на сьогодні, `/report` — звіт по воронці, `/export` — база в Excel, `/new` — нова розмова.
- Щобудня о 9:00 бот надсилає план на день (інтерв'ю й кому пора написати повторно), щопонеділка — звіт по воронці. Час змінюється в `.env`.

## Як оновити бота

Після змін на Mac повторіть команду `rsync` з кроку 4, потім на сервері:

```
cd /opt/recruiting-bot && docker compose up -d --build
```

База, резюме і ключі лежать у папці `data/` і під час оновлення не зникають.

Ваші приклади й playbooks бот зберігає на сервері в `/opt/recruiting-bot/.claude/`. Щоб не перезаписати їх версіями з Mac, спершу заберіть їх на Mac:

```
rsync -av root@IP-АДРЕСА:/opt/recruiting-bot/.claude/ ~/Desktop/"AI агент"/.claude/
```

## Резервна копія

Уся база — один файл. Щоб скопіювати її на Mac:

```
scp root@IP-АДРЕСА:/opt/recruiting-bot/data/recruiting.db ~/Desktop/
```

## Якщо щось не працює

Подивіться журнал бота: `docker compose logs --tail 50`.

## Безпека

- Файл `.env` містить ключі. Не публікуйте його і не надсилайте в чати.
- Резюме — це персональні дані кандидатів. Вони зберігаються лише на вашому сервері (`data/resumes/`) і передаються в Claude API для аналізу. Видаляйте їх, коли вони вже не потрібні.
