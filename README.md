# Рекрутинговий агент

Набір навичок для Claude Code, які допомагають рекрутерці на українському ринку: від аналізу вакансії до повідомлень кандидатам. Працює українською.

Створено на основі [michaljuhas/recruiting-skills](https://github.com/michaljuhas/recruiting-skills) (MIT): навички перекладено й адаптовано під Україну (Djinni, DOU, Work.ua, Telegram, ФОП і Дія.City, бронювання, оплата в USD).

## Що потрібно

- Підписка Claude (Pro або Max) і **Claude Code**: застосунок Claude Desktop, розширення для VS Code або термінал. Нічого доплачувати не треба.
- Telegram-бот із цього репозиторію **не потрібен**: він необов'язковий (див. нижче).

## Навички

| Навичка | Що робить | Як попросити |
|---------|-----------|--------------|
| job-requirement-analysis | Розбирає вакансію за 19 пунктами, готує запитання до наймаючого менеджера | «Розбери вакансію» |
| candidate-icp-builder | Складає профіль ідеального кандидата і таблицю оцінки | «Склади профіль кандидата» |
| job-seller | Робить вакансію привабливою, переписує текст | «Перепиши вакансію для Djinni» |
| sourcing-strategy-generator | Пошукові запити й чекліст каналів | «Де шукати кандидатів?» |
| candidate-screener | Оцінює та ранжує кандидатів | «Оціни цього кандидата: [профіль]» |
| outreach-writer | Повідомлення в LinkedIn, Djinni, Telegram, email і нагадування | «Напиши кандидату» |

## Як зробити свою копію

1. Натисніть зелену кнопку **Use this template → Create a new repository** (або **Fork**) і створіть власний репозиторій. Краще приватний, якщо додаватимете туди свої матеріали.
2. Склонуйте його на комп'ютер (або завантажте ZIP: **Code → Download ZIP**) і відкрийте папку в Claude Code.
3. Скопіюйте `.claude/profile.example.md` у `.claude/profile.md` і заповніть про себе.
4. Перевірте агента: «Розбери вакансію з examples/test-vacancy.md».

Ваші особисті файли (`profile.md`, `tone.md`, приклади в `my-examples/`, playbooks) git не відстежує: вони лишаються лише у вас, навіть якщо репозиторій публічний.

## Голосові повідомлення (необов'язково)

Агент може розуміти голосові повідомлення в Telegram. Розпізнавання працює локально на вашому Mac через модель Whisper, безкоштовно. Щоб увімкнути, двічі клікніть `tools/setup-voice.command`: встановлення займе кілька хвилин і приблизно 2 ГБ місця.

## Як навчити агента вашого стилю

- `my-examples/` у кожній навичці: ваші вдалі вакансії, повідомлення, оцінки.
- `.claude/skills/outreach-writer/my-examples/tone.md`: ваш стиль повідомлень (скопіюйте з `tone.example.md`).
- `.claude/playbooks/`: що спрацювало на кожній ролі (шаблон: `_шаблон.md`).

## Додатково: Telegram-бот (необов'язково, платно)

Для тих, хто хоче користуватися агентом з телефона. Бот уміє те саме, що й навички, а також веде базу кандидатів, читає резюме (PDF, DOCX), надсилає нагадування, щоденний план і тижневий звіт, планує інтерв'ю в Google Calendar.

Важливо: бот звертається до Claude через **Claude API**, а за API платять окремо, за кожне використання. Підписка Claude на нього не поширюється. Ще знадобиться сервер, приблизно $5–10 на місяць. Як запустити: [DEPLOY.md](DEPLOY.md).

Код бота лежить у `bot/`, тести — у `tests/`. Якщо бот вам не потрібен, просто не звертайте на ці папки уваги.
